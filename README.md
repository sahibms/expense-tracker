# Expense Tracker App

A responsive Expense Tracker application built with React.js to manage income and expenses and track the available balance.

## Features

- Add income and expense transactions
- Edit existing transactions
- Delete transactions
- Automatically calculate the balance
- Track income and expenses
- Save transaction data using Local Storage
- Maintain data after page refresh
- Responsive design for mobile and desktop devices

## Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Local Storage

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sahibms/expense-tracker.git
```

### 2. Navigate to the project folder

```bash
cd expense-tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
